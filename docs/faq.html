常见问题

目前只收录了已经确认的兼容性问题，其余条目待补充。

提问之前先对照 安装前检查。多数"用不了"的情况是环境没满足，不是软件故障。

Windows 11 上无法使用

现象：部分用户在 Windows 11 上无法使用。

处理：切换至 Windows 10 系统使用。

注意这是部分用户的情况，不是所有 Windows 11 都不支持。

网吧 / 无盘系统

现象：网吧等无盘系统环境下无法使用。

处理：无解。无盘系统属于明确不支持的场景，见 安装前检查 · 不支持的场景。

显示器没有输出

先查这两项（其余排查步骤待补充）：

  • 显示器的 HDMI / DP 线是否直连显卡，而不是接在主板上。
  • 笔记本是否使用了外接显示器，且 BIOS 显卡模式为 dGPU only（不能是 iGPU only 或 Hybrid）。
