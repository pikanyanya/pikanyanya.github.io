安装前检查

喵喵对 BIOS 设置和显卡接线方式有硬性要求。下面几项逐条确认，环境不满足时安装后无法正常使用。

设置项速查
设置项要求适用范围
虚拟化（VT-x / SVM Mode）打开全部
IOMMU打开全部
4G 以上编解码 / MIMO关闭全部
显卡工作模式dGPU only笔记本
显示器接线HDMI / DP 直连显卡全部

1. BIOS 设置

开机进入 BIOS，按下面三项设置。不同主板厂商的菜单名称与位置不一样，按含义找对应选项。

  1. 打开虚拟化选项

    Intel 与 AMD 平台的选项名不同：

    • Intel：Intel Virtualization Technology (VT-x)
    • AMD：Secure Virtual Machine (SVM Mode)

  2. 打开 IOMMU

    选项名为 IOMMU，部分主板上也可能标注为对应的厂商名称，设置为打开 / Enabled。

  3. 关闭 4G 以上编解码 / MIMO

    即 Above 4G Decoding 与 MIMO 相关选项，设置为关闭 / Disabled。

改完记得保存并重启 BIOS，否则设置不生效。

2. 笔记本用户注意

笔记本有两条额外要求：

  1. 必须使用外接显示器。
  2. BIOS 中显卡模式设置为 dGPU only。
    不要使用 iGPU only 模式，也不要使用 Hybrid（混合）模式。

3. 显示器接线

显示器用 HDMI 或 DP 线直接连到独立显卡的接口上，不要连到主板上的视频接口。

接错口是最常见的问题

主板视频接口走的是核显输出，接到那里不满足要求。确认线材插在显卡自带的接口上。

4. 不支持的场景

以下情况无法使用

  • 网吧等无盘系统无法使用。
  • 部分用户的 Windows 11 可能无法使用，可切换至 Windows 10 系统使用。

检查完之后

以上项目都确认后，进入 安装。若安装或使用中遇到问题，见 常见问题。
